換站資料備份

GitHub Pages 與 Cloudflare 網址的瀏覽器資料各自儲存。請先在舊站匯出，再於新站開啟本頁匯入。

備份包含答案顯示、日夜偏好及舊版私人題目儲存資料。舊版私人題目只保留原始資料，不會重新出現在題庫或送交協作。現有測驗進度只留在當次頁面，請先完成測驗再換站。

備份不含登入憑證、密碼或對戰房間憑證。兩站使用同一個 Supabase 帳號，但需要分別登入；已送交協作的資料由原資料庫保留。

1. 在舊站匯出

備份可能含私人題目，請保存在自己的裝置，勿上傳到公開儲存庫。本頁不會把備份傳送到伺服器。

2. 在新站匯入

先檢查檔案，再確認匯入。已有同名資料會保留；容量不足時會顯示已匯入與失敗數量，來源檔及舊站資料均不會刪除。
